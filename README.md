# Holyrood Forecast Prototype
## COMP09049 Study Project: David McGowan (B00162734)
> **Note:** This README was added on 03/04/2026, after the submission date of 01/04/2026.
> The core codebase and report are unchanged from the original submission.

## Overview
A prototype prediction engine that forecasts Scottish Parliament (Holyrood) regional list seat allocations using polling data and the D'Hondt seat allocation algorithm.

## Requirements
- Python 3.11
- Dependencires are listed in the 'doc/requirements.txt' file.

## Installation
```bash
pip install -r docs/requirements.txt
```

## Usage
Run from the project root directory:
```bash
python src/main.py
```

## Running Tests
```bash
pytest test/
```
